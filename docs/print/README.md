# Léto s Ensanou — podklad pro papírové kvízy

Finální obsah pro sazbu papírové (offline) verze kvízu. Určeno pro tisk a rozdání
návštěvníkům, kteří nemají telefon nebo nechtějí skenovat QR kód. Obsah je 1:1
shodný s online verzí a generuje se přímo z ní.

## Soubory v této složce

| Soubor | Použití |
|--------|---------|
| `kviz-ensana-leto-{cs,de,en,ru}.md` | Čistý editovatelný text (k nasypání do Affinity / Canvy) |
| `kviz-ensana-leto-{cs,de,en,ru}.html` | Hotový tisknutelný A4 layout (náhled + přímý tisk jako záloha) |

## Formát a branding

- **Formát:** A4 na výšku, vše na 1 straně (10 otázek + formulář)
- **Barvy (Ensana):** indigo `#2c2a6b` (nadpisy, text), žlutá `#f4c531` (badge/CTA), béžová `#faf7ef` (box výhry)
- **Písma:** nadpisy Cormorant Garamond (serif), text DM Sans (sans-serif)
- **Struktura:** badge → nadpis → úvod → box s výhrou → 3 kroky „jak se zapojit“ → 10 otázek (9× výběr a–d k zakroužkování + 1 otevřená) → kontaktní formulář (jméno, příjmení, e-mail) → **dva oddělené souhlasy** (povinný = účast, nepovinný = newsletter — nesmí být předvyplněný) → datum + podpis → patička s odkazem na úplná pravidla

## Tisk a sběr

- Vytiskněte oboustranně jen pokud chcete více jazyků na jednom listu; jinak 1 list = 1 jazyk.
- Doporučení: k lístku připojit i malý QR kód na `marienbad.com/ensanaleto` (kdo přece jen telefon má).
- Vyplněné lístky se souhlasem se zadají do MailerLite (skupina „Quiz — Léto s Ensanou“).
  E-mail zařaďte do newsletter skupiny **jen** pokud zaškrtl(a) druhý (nepovinný) souhlas.
