# 📘 Your Free Marienbad Guide — Content Package

**Read this first.** This ZIP contains everything a designer (or a new Claude Cowork
session driving Affinity Publisher) needs to lay out the lead-magnet PDF titled
**“Your Free Marienbad Guide.”**

> *The best insider tips, seasonal recommendations, and fresh stories, delivered straight
> to your inbox.*

The guide is the reward visitors receive after leaving their email address on
marienbad.com. Its job is to make them fall for Marienbad and book a stay with **Ensana**.

---

## What’s in this folder

| File | What it is |
|------|-----------|
| `README-START-HERE.md` | This file. |
| `01_GUIDE-CONTENT.md` | **The full, final copy** — page by page (20 pages). Set this text as written. |
| `02_DESIGN-BRIEF.md` | Brand colours, fonts, layout language, page plan, output settings. |
| `03_IMAGE-MANIFEST.md` | Which image goes on which page + placeholder notes. |
| `facts-reference.json` | The Ensana knowledge base — the single source of truth for every fact. Don’t print anything that contradicts it. |
| `images/` | 30 ready-to-place photos + logos (named to match the copy). |

## How to build the PDF (suggested prompt for the next Cowork/Affinity session)

Paste something like this into the new session, with this ZIP attached:

> “Attached is a content package for a 20-page A4 lead-magnet PDF called *Your Free
> Marienbad Guide*. Use `01_GUIDE-CONTENT.md` as the exact copy (one guide page per
> `PAGE` heading), follow `02_DESIGN-BRIEF.md` for the brand system (Ensana palette:
> indigo / turquoise / yellow / aubergine / beige; font *Branding* or a Poppins/Montserrat
> stand-in), and place images per `03_IMAGE-MANIFEST.md` from the `images/` folder.
> Build it in Affinity Publisher and export a screen-quality RGB PDF. Leave the 🔲
> placeholder slots as grey boxes — I’ll drop in hi-res photos from our own database.”

---

## Important notes

1. **Facts are locked.** Everything in the copy comes from `facts-reference.json` or the
   marienbad.com site. Do **not** add invented prices, exact festival dates or medical
   efficacy claims. For live festival dates, pull them from marienbad.com at layout time.
2. **Images are web-resolution** (≈1200–1600 px). Perfect for an email/download PDF;
   for any full-bleed **print** you’ll want to swap in hi-res originals — the manifest flags
   which slots matter most (cover, back cover, hotel hero, Roman Baths).
3. **Placeholders** (`🔲` in the manifest): page 7 optional image, page 13 golf photo,
   page 18 map/station. Leave grey boxes; the client supplies these.
4. **Diacritics matter.** Keep *Mariánské Lázně, Křížový pramen, Václav Skalník, Teplá,
   Kladská, Plzeň, MUDr. Markéta Hovorková* exactly as written.
5. **Two exports** recommended (see design brief §1): a small RGB screen PDF for email,
   and — only if it’ll be printed — a 300 dpi CMYK version with bleed.

Everything is ready to typeset. Enjoy — and welcome to Marienbad. 🕊️
